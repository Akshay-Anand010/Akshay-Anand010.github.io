ML Visual Lab is an interactive site of visual explanations for classical machine learning and deep learning. Akshay built it so the ideas can be seen, not only read. The lab includes chapters on linear models, neural nets, CNNs, attention, and related topics. The public site is https://akshay-anand010.github.io/ml-visual-lab/ and the code is https://github.com/Akshay-Anand010/ml-visual-lab.
